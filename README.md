# Landing page MaxProff 
Responsive design with Figma mockup, Price calculator, Tabs, Carousel, Accordion list, Bootstrap layout

## Technologies Used

- HTML5
- CSS3
- SCSS
- JavaScript
- Gulp
- PerfectPixel
